Read installation guide ↗

Requires macOS, Xcode Command Line Tools, and Python 3. Not a notarized one-click download.

Where does my sign-in go?

Pace reads your existing Codex sign-in locally and sends its token only to chatgpt.com for usage requests. It does not send credentials to this website or put them in the embedded dashboard.

Is this an official OpenAI product?

No. Pace is an independent experiment, unaffiliated with OpenAI or Airtable. It uses undocumented endpoints that can change. Source reporting may lag, and estimates are not invoices.

How do updates work?

Ask your agent to update Pace, or run the update script from your checkout. It pulls main and rebuilds locally while preserving preferences. Updates are not automatic.
